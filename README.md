During the lab sessions, the Google Colab notebooks (.ipynb files) were originally uploaded to the repository weekly as each lab was completed. However, while pushing the recent Tic-Tac-Toe lab files from VS Code using Git, a repository synchronization issue occurred because the remote repository already contained commits that were not present locally. To resolve the conflict, the repository history was overwritten during the push process, which caused the previously uploaded notebook files to disappear from the GitHub repository. The original notebooks were still safely stored in Google Colab/Google Drive, so they were downloaded again and re-uploaded together to restore the missing lab work in the repository. This is why several notebook files appear to have been uploaded at the same time even though they were completed during different lab sessions.
